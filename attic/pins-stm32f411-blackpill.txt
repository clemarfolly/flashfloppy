FlashFloppy on STM32F411CEU6 "BlackPill" (FloppyEmuBlackpillPerfBoard)
======================================================================

MCU: STM32F411CEU6 (512kB Flash, 128kB RAM), 25MHz HSE.
Clocks: SYSCLK=AHB=APB2=72MHz, APB1=36MHz, USB=48MHz.
  (FlashFloppy samples flux at 72MHz; SYSCLK must be a multiple of that.)

Flash layout (F411 has unequal sectors):
  0x08000000-0x0800BFFF  Sectors 0-2 (3x16kB)  Bootloader
  0x0800C000-0x0805FFFF  Sectors 3-6           Firmware (336kB)
  0x08060000-0x0807FFFF  Sector 7 (128kB)      Config (FF.CFG cache)

Floppy (34-pin header J3):
--------------------------
Inputs: all are FT (5v tolerant) per the STM32F411xE datasheet, provided
the pin is not in analog mode (the firmware never uses analog mode on them).
 PA0   SEL    (via 100R + 3V3 zener; source chosen by jumper J4:
               SEL0 / SEL1 / MTRON)
 PA1   STEP   (TIM2_CH2, AF1)   1k pull-up to 5v
 PB0   DIR                      1k pull-up to 5v
 PB4   SIDE                     1k pull-up to 5v
 PB9   WGATE                    1k pull-up to 5v
 PA8   WDATA  (TIM1_CH1, AF1 -> DMA2 Stream6 Ch0)
 MOTOR is not connected to the MCU: firmware sees "motor always on"
       (PB15 pulled down internally).

Outputs: MCU -> 74HC04 inverter -> BC337 open collector (1k pull-up 5v).
Overall polarity is unchanged: MCU LOW = bus line asserted (LOW).
Outputs are push-pull (required to drive the 74HC04 inputs).
 PB7   pin 2  (CHNG / DENSEL; see pin02= in FF.CFG)
 PB8   pin 8  INDEX
 PB6   pin 26 TRK0
 PB5   pin 28 WRPROT
 PB2   pin 34 (RDY / CHNG; see pin34= in FF.CFG)
 PA7   pin 30 RDATA (TIM3_CH2, AF2; TIM3_UP -> DMA1 Stream2 Ch5)

Buttons & Jumpers (active low, internal pull-ups):
---------------------------------------------------
 PA3   BUT_L  (Left)
 PA4   BUT_R  (Right)
 PA5   JA     (= Select button, as on standard Gotek)
 PA2   JB     (also speaker output)
 PB1   JC     (config/interface select at boot)
 Left+Right together = Select.

Display header J6:
------------------
 PB10  I2C2_SCL (AF4)   / LED 7-seg DAT
 PB3   I2C2_SDA (AF9)   / LED 7-seg CLK   (BlackPill has no PB11)
 I2C2 DMA: TX = DMA1 Stream7 Ch7, RX = DMA1 Stream3 Ch7

USB host (J5, USB-A):
---------------------
 PA11  USB_DM (AF10)
 PA12  USB_DP (AF10)
 VBUS sensing disabled (PA9 is used by the serial console).

Debug console (J1), debug builds only:
--------------------------------------
 PA9   USART1_TX (AF7), 3Mbaud 8N1
 PA10  USART1_RX (AF7)

Other:
------
 PA13/PA14  SWD. After boot these become alternative rotary-encoder
            inputs (as on 48-pin Gotek boards), so attach the debugger
            with "connect under reset".
 PC13       BlackPill on-board LED (unused)
 PC14/PC15  32kHz crystal (unused)
 Unused, pulled up: PA6, PA15, PB12-PB15

Interrupts:
-----------
 EXTI0 (6)       SEL
 EXTI4 (10)      SIDE
 EXTI9_5 (23)    WGATE
 EXTI15_10 (40)  MOTOR/CHGRST/rotary
 TIM2 (28)       STEP
 DMA1_S2 (13)    RDATA DMA
 DMA2_S6 (69)    WDATA DMA
 DMA1_S3 (14)    I2C2 RX DMA
 DMA1_S7 (47)    I2C2 TX DMA
 I2C2 (33/34)    Display
 TIM5 (50)       Timer subsystem
 OTG_FS (67)     USB
 SPI4/SPI5 (84/85) used as software IRQs

Floppy drive 34-pin Shugart(-ish) interface. For reference:
-----------------------------------------------------------
  2: <- CHNG(Amiga) / -> DENSEL(PC)
  4: -- (INUSE, jumper J4 to GND)
  8: <- INDEX
 10: -> SEL0
 12: -> SEL1
 14: -> SEL2
 16: -> MTR
 18: -> DIR
 20: -> STEP
 22: -> DKWD
 24: -> DKWE
 26: <- TRK0
 28: <- WRPROT
 30: <- DKRD
 32: -> SIDE
 34: <- CHNG(PC) / RDY(Amiga)
All odd pins are ground.
